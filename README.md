# 方法学验证与统计分析 Agent — 公开演示版

IVD / TDM（治疗药物监测）方法学验证的交互式演示平台。

> **数据声明**：本演示版所有产品注册证号、溯源信息均为**示例占位符**，不对应任何真实产品或企业。功能演示使用的数据为公开法规框架与模拟测量值。

## 在线演示

启用 GitHub Pages 后访问：`https://qinlinjuan.github.io/mva-platform-demo/`

## 功能

| 模块 | 说明 |
|------|------|
| 驾驶舱 | 4 款 TDM 产品概览、IVDR/NMPA 法规切换 |
| 差距识别 | 对照 23 项性能指标，自动识别缺失项 |
| 验证方案 | 生成实验设计、接受标准、法规依据 |
| 统计计算器 | 精密度、线性、方法学比对、正确度、回收率、LoB/LoD/LoQ、干扰率 |
| 符合性判定 | 接受标准 Pass/Fail 自动判定 |
| 报告生成 | 注册报告结构预览、打印/PDF、HTML 下载 |
| 法规依据 | IVDR / NMPA 核心法规清单 |

## 技术特点

- **纯静态**：无后端、无数据库，所有计算在浏览器本地完成
- **确定性**：统计计算由原生 JS 引擎实现（与 Python 版算法一致），结果可复现
- **即开即用**：双击 `index.html` 即可运行，或部署到任意静态托管

## 重要声明

本平台输出的方案与报告基于公开法规/指导原则的结构化摘要，仅供研发与申报准备参考，**不构成注册申报的正式结论**。正式申报前必须以 NMPA/CMDE 或欧盟官方发布的最新有效版本为准逐条核对。
